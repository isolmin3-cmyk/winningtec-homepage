# 위닝텍 홈페이지
엑셀의 7개 섹션 순서를 적용한 반응형 정적 홈페이지입니다. 로그인 없이 사용하는 콘텐츠 관리자페이지를 포함합니다.

## 미리보기
`python3 -m http.server 8080 --directory dist` 실행 후 http://localhost:8080 을 엽니다. 빌드와 패키지 설치가 필요하지 않습니다.

## 수정
- 문구와 연락처: `dist/index.html`
- 기본 디자인 토큰: `dist/tokens.css`
- 페이지 배치: `dist/style.css`
- 메뉴 동작: `dist/script.js`
- 실제 제품·설비 이미지: `dist/assets/`

## 콘텐츠
사용자가 제공한 회사 소개 엑셀의 문구·사진과 회사소개서의 연락처를 사용했습니다. 인증서 원본과 거래처 로고는 제공되지 않아 다운로드 기능이나 로고를 만들지 않았습니다. 연혁은 실제 사건이 없어 회사정보로 구성했고, 검증되지 않은 설립일은 게시하지 않았습니다. 지도는 실제 지도가 아닌 위치 안내이며 정식 지도 서비스의 검색 링크를 제공합니다.

## 배포
Sites 배포는 `.openai/hosting.json`의 `dist`를 사용합니다. GitHub 저장소는 별도로 동기화합니다. GitHub 업로드와 GitHub Pages 활성화는 서로 다릅니다.

## 관리자 사용
관리자 주소는 `admin.html` 또는 `admin/`입니다. 그린토크·GINOVO의 섹션 메뉴, 문구·이미지 편집 카드, 저장, 기본값 복원, 페이지 확인 구조를 위닝텍의 7개 섹션에 적용했습니다.

1. 문구·이미지를 수정하고 섹션의 변경사항 저장을 누릅니다.
2. 같은 브라우저에서 홈페이지를 열면 저장 내용이 적용됩니다. 다른 기기나 방문자에게는 공유되지 않습니다.
3. 전체 방문자에게 반영하려면 전체 변경사항 내보내기로 `content.json`을 다운로드합니다.
4. GitHub의 `dist/content.json`을 이 파일로 교체하고 커밋합니다. Pages 자동 배포 후 공개 홈페이지에 반영됩니다.

파일 불러오기로 다른 브라우저에 편집 내용을 옮길 수 있습니다. 문구·이미지는 IndexedDB에 저장됩니다. 브라우저 데이터를 삭제하면 로컬 수정이 사라지므로 내보낸 파일로 보관하세요. 로그인·Supabase 공유 쓰기·비밀 토큰은 포함하지 않습니다.
기본값 복원은 해당 섹션의 브라우저 수정을 제거하고 게시된 기본값으로 돌아갑니다. 저장 전 내용도 미리보기와 내보내기에 포함됩니다.

## 홈페이지 직접 편집 (2026-10-13)
`admin.html`은 `index.html?edit=1`로 연결됩니다. 별도 관리 폼 없이 실제 홈페이지에서 영역의 편집 버튼을 눌러 문구를 입력하고 이미지·배경이미지를 교체합니다. 화면 하단의 저장은 현재 브라우저에 적용하고, 취소는 현재 영역의 편집 전 상태로 되돌립니다. 공개 게시 방식은 기존과 동일하게 content.json 내보내기 후 GitHub dist/content.json 업로드입니다.
